Web Development in the AI Era

A one-day seminar for non-technical creators to learn how websites work, how AI can support the development process, and why understanding still matters.

About the Seminar

This seminar introduces participants to HTML, CSS, basic JavaScript, and focused AI use inside the development process. Students begin by asking AI to create a website with little direction, then improve that result by learning how structure, design, purpose, and prompt clarity shape better outcomes.

What Participants Will Learn

Web Foundations

Understand the role of HTML, CSS, and JavaScript in building modern websites.

AI Prompting

Learn how more detailed prompts produce more useful, accurate, and relevant output.

Critical Thinking

Evaluate AI-generated code instead of relying on it blindly.

Practical Application

Create and improve a simple website that can be shared and discussed.

Seminar Agenda

1. First Attempt with AI

Participants ask AI to create a website with minimal guidance and review the results.

2. Web Development Basics

We break down HTML, CSS, and JavaScript to understand what each part of the website does.

3. Prompt Refinement

Participants improve their original prompts using clearer goals, features, and constraints.

4. Final Comparison

We compare the original and revised websites to see how better prompting improves results.

By the end of the seminar, participants should be able to explain the structure of a simple webpage, identify weaknesses in vague AI output, and rewrite prompts that produce more useful, intentional results.

Why This Matters

AI can generate code quickly, but it cannot replace clear thinking. This seminar helps students understand how to work with AI as a tool—rather than treat it as a substitute for understanding how websites actually function.

Ideal Audience

  • Communications and journalism students
  • Design and media creators
  • Anyone curious about web development and AI
